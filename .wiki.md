# Project Summary
PetControl is an advanced pet management system designed to enhance the care and administration of pets for owners, veterinarians, and administrators. It facilitates efficient management of pet records, appointments, and medical histories through a modern web application that offers a responsive and user-friendly interface.

# Project Module Description
The system includes the following functional modules:
- **Authentication**: User registration and login with improved password validation.
- **User Management**: Admin can create, edit, and delete user accounts while protecting certain predefined users.
- **Pet Management**: Users can manage their pets, with admins overseeing all pet records.
- **Veterinary Records**: Veterinarians can add and manage medical records, treatments, and vaccinations.
- **Dashboard**: Admin dashboard for statistics and quick access to functionalities.

# File Description Inventory
- **Backend**: Contains server-side logic, configurations, and database interactions.
- **Frontend**: Contains the client-side application built with React, including components, pages, and styling.

# Technology Stack
- **Backend**: Spring Boot 3.2.0, Java 21, MySQL (XAMPP), JWT for authentication.
- **Frontend**: React 18, Vite, Axios for HTTP requests, Bootstrap 5 for UI.

# Usage
### Installation
1. **Backend**:
   ```bash
   cd /workspace/petcontrol-backend
   ./mvnw spring-boot:run
   ```

2. **Frontend**:
   ```bash
   cd /workspace/petcontrol-frontend
   npm install
   npm run dev
   ```

### Running the Application
- The backend will run on port 8080.
- The frontend will run on port 5173.
