# Project Summary
PetControl is a comprehensive pet management system designed to facilitate the care and administration of pets. It allows users, including pet owners, veterinarians, and administrators, to manage pet records, appointments, and medical history efficiently. The application leverages modern web technologies to provide a responsive and user-friendly interface, ensuring ease of access and functionality for all roles involved.

# Project Module Description
The system consists of the following functional modules:
- **Authentication**: User registration and login using JWT.
- **User Management**: Admin can create, edit, and delete user accounts.
- **Pet Management**: Users can add, edit, view, and delete their pets; admins can manage all pets.
- **Veterinary Records**: Veterinarians can add medical records, treatments, and vaccinations for pets.
- **Dashboard**: Admin dashboard displaying statistics and quick access to various functionalities.

# File Description Inventory
- **Backend**: Contains the server-side logic, configurations, and database interactions.
- **Frontend**: Contains the client-side application built with React, including components, pages, and styling.

# Technology Stack
- **Backend**: Spring Boot 3.2.0, Java 21, MySQL (XAMPP), JWT for authentication.
- **Frontend**: React 18, Vite, Axios for HTTP requests, Bootstrap 5 for UI.

# Usage
### Installation
1. **Backend**:
   ```bash
   cd /workspace/petcontrol-backend
   ./mvnw spring-boot:run
   ```

2. **Frontend**:
   ```bash
   cd /workspace/petcontrol-frontend
   npm install
   npm run dev
   ```

### Running the Application
- The backend will run on port 8080.
- The frontend will run on port 5173.
