# Project Summary
PetControl is a comprehensive pet management web application designed to streamline the registration, tracking, and management of pet information. Utilizing a Spring Boot backend with a robust RESTful API, the application offers a dynamic user experience through a React frontend powered by Vite. Security is prioritized with JWT authentication and role-based access control, ensuring safe user interactions. The system is optimized for MySQL using XAMPP, catering to three user roles: CLIENTE, VETERINARIO, and ADMIN, each with distinct functionalities.

# Project Module Description
The project consists of two main modules:
1. **Backend (Spring Boot)**: 
   - Provides a REST API for pet management and user authentication.
   - Implements JWT for secure access and role-based permissions.
   - Supports CRUD operations for pets and user management.
   - Fully developed with complete API documentation and Swagger integration.

2. **Frontend (React)**: 
   - A Single Page Application (SPA) that interacts with the backend API.
   - Features user interfaces for pet management, including CRUD operations.
   - Employs JWT for authentication and session management.
   - Responsive design with modern UI components.

  - React Router

  - Tailwind CSS

# Usage
### Backend Setup
1. Navigate to the backend directory:
   ```bash
   cd petcontrol-backend
   ```
2. Build and run the backend:
   ```bash
   ./mvnw spring-boot:run
   # For Windows
   mvnw.cmd spring-boot:run
   ```

### Frontend Setup
1. Open a new terminal and navigate to the frontend directory:
   ```bash
   cd petcontrol-frontend
   ```
2. Install dependencies (only the first time):
   ```bash
   npm install
   ```
3. Run the frontend in development mode:
   ```bash
   npm run dev
   ```

### Access
- The backend will be available at `/api`.
- The frontend will be available at the specified port during development.
